# Contributing

This is the default contributing guide for every repository in [github.com/ohtf](https://github.com/ohtf) that does not have its own. Where a project has its own guide, that guide wins for that project.

You do not need permission to start: read the project's README, then open an issue or pull request. Every OHTF project follows the same few rules:

1. **Be decent.** Follow the [code of conduct](CODE_OF_CONDUCT.md).
2. **Sign off your commits** under the [Developer Certificate of Origin](https://openhealthtechnology.org/community/dco/): `git commit -s`.
3. **Report vulnerabilities privately**, never in a public issue. See the [security policy](SECURITY.md).
4. **Never include real patient data** in issues, pull requests, test fixtures, screenshots or logs. Use synthetic data, and report any real data you find privately.

More, including contributing alongside a day job: <https://openhealthtechnology.org/community/>.
