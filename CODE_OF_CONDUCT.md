# Code of conduct

This is the default code of conduct for every repository in [github.com/ohtf](https://github.com/ohtf) that does not have its own.

OHTF adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/) for all OHTF projects and community spaces. Health care adds some expectations of its own:

- **Patient confidentiality is not negotiable.** Never share patient-identifiable information in any OHTF space, even as an example.
- **Disagree about the evidence, not the person.** Keep clinical and technical debates about the work.
- **Respect professional boundaries.** Expertise is welcome; status is not an argument.

Report behaviour that breaks this code of conduct to [conduct@openhealthtechnology.org](mailto:conduct@openhealthtechnology.org). Reports are handled in confidence. If the report concerns someone who would normally receive it, say so and it will be handled by someone else.

Full text and enforcement: <https://openhealthtechnology.org/community/code-of-conduct/>.
