# ohtf/.github

Organisation-wide GitHub files for the [Open Health Technology Foundation](https://openhealthtechnology.org).

| Path | Effect on GitHub |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The public profile shown at <https://github.com/ohtf>. |
| [`SECURITY.md`](SECURITY.md) | Default security policy for OHTF repositories without their own. |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct for OHTF repositories without their own. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contributing guide for OHTF repositories without their own. |

GitHub only uses these defaults when a repository has no file of the same name. This repository must stay public for them to apply.

The canonical versions of these policies live on [openhealthtechnology.org](https://openhealthtechnology.org); these files summarise and link to them. Change the website first, then bring these in line.
