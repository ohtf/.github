# Security policy

This is the default security policy for every repository in [github.com/ohtf](https://github.com/ohtf) that does not have its own.

**Do not report suspected vulnerabilities in public issues, discussions or pull requests.**

Report them privately, either:

- through GitHub's private vulnerability reporting on the affected repository (the **Security** tab, then **Report a vulnerability**); or
- by email to [security@openhealthtechnology.org](mailto:security@openhealthtechnology.org).

If the issue could affect patient safety, clinical workflow or patient-identifiable data, say so clearly. We triage it as both a security finding and a potential clinical safety hazard. Never include real patient data in a report.

The full policy, including what to include, response times and disclosure, is at <https://openhealthtechnology.org/community/security/>.
